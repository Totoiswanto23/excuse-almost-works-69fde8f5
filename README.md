## The entry

> Sorry boss, my train's cancelled and the replacement bus broke down halfway here.

13 words, 81 characters, one line. The joke is in the excuse's own logic: the first half is boring and specific enough to believe, the second half stacks one failure too many. A tired manager buys the cancelled train; the replacement bus breaking down halfway there is the tell — the kind of escalating bad luck only a liar (or a gamer with a launch-day plan) would report in one hurried text.
